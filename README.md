# Cypher - 資訊安全與密碼學技術庫

本專案主要用於整理與存放各類**資訊安全（Cybersecurity）**與**密碼學（Cryptography）**相關的技術實作、演算法、工具與研究資源。

---

## 專案模組架構

- **[`vigenere-vault/`](./vigenere-vault/)**：
  - 基於隨機加鹽（8-digit Salt）、SHA-256 金鑰延伸與擴充版維吉尼亞密碼（Vigenère Cipher）的命令列機密管理器。
  - 具備單一加密檔案中多金鑰共存、驗證與隔離特性。
  - 支援終端機、純文字檔與 Markdown 檔案解密輸出與機密增刪管理。
- **後續擴充計畫**：
  - 現代對稱式加密標準（AES-GCM、ChaCha20-Poly1305）實作。
  - 非對稱式加密（RSA、ECC）與數位簽章技術研究。
  - 常見網路安全協定、漏洞分析與 PoC 工具。
  - 資安實務演練與自動化安全工具。
